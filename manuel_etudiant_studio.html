Section 1

Qu'est-ce que Green Lab Studio ?

Un générateur de modules pédagogiques complets, propulsé par l'IA

Présentation générale

Green Lab Studio est un outil qui permet de créer automatiquement des modules pédagogiques complets à partir d'une simple description. En quelques secondes, l'IA génère pour vous :

  • Un cours théorique structuré avec sections progressives
  • Des exercices pratiques et mises en situation réelles
  • Un quiz d'évaluation avec feedback automatique
  • Des flashcards pour la mémorisation
  • Une check-list terrain et un mémo expert
  • Un cas industriel ou terrain ancré dans votre domaine
  • Un plan de révision jour par jour adapté à votre rythme
  • Des ressources vidéo YouTube ciblées sur le module

Tout cela sans avoir à rédiger une seule ligne — vous décrivez, l'IA construit.

Section 2

Première connexion — Clé API Gemini

Green Lab Studio fonctionne exclusivement avec Gemini (Google) — une clé gratuite en moins de 2 minutes

⚠️ Indispensable avant de commencer Green Lab Studio nécessite une clé API pour fonctionner. Sans elle, aucune génération n'est possible. La procédure prend moins de 2 minutes, et Google propose une clé entièrement gratuite.

2.1 — Créer votre clé Gemini

L'application détecte automatiquement la clé dès que vous la collez — aucune configuration manuelle nécessaire.

✨ Gemini Flash

Gratuit, rapide, quota généreux — le seul fournisseur utilisé par l'application.

  • Clé commence par AIza
  • Quota gratuit disponible
  • Inscription : aistudio.google.com/apikey
1

Créez un compte Google

Allez sur aistudio.google.com/apikey. Aucune carte bancaire requise (quota gratuit). Connectez-vous avec votre compte Google.

2

Créez une clé API

Cliquez sur Create API Key. Donnez-lui un nom (ex : "GreenLab").

3

Copiez la clé immédiatement

La clé n'est affichée qu'une seule fois. Copiez-la dès sa création — elle ne sera plus lisible après fermeture de la fenêtre.

2.2 — Saisir la clé dans l'application

1

Revenez sur Green Lab Studio

L'onglet de l'application est resté ouvert. Pas besoin de le recharger.

2

Collez la clé dans le champ en haut de la sidebar

Le champ affiche le placeholder AIza…. Collez votre clé avec Ctrl+V (ou ⌘V sur Mac). Elle est masquée par défaut pour la sécurité.

3

Un badge de confirmation apparaît

L'application reconnaît automatiquement la clé et affiche un badge ✨ Gemini sous le champ. La clé est sauvegardée localement dans votre navigateur.

🔒 Ne partagez jamais votre clé API Votre clé est personnelle. Ne la publiez pas, ne la mettez pas dans un email. Elle permet de faire des appels API à votre nom et à votre quota.

Section 3

Créer un module avec l'Assistant IA

L'interface de chat est le cœur de Green Lab Studio — tout commence ici

Comment fonctionne l'Assistant ?

L'Assistant IA est une interface de chat qui comprend vos demandes en langage naturel. Vous lui décrivez le module que vous voulez — domaine, compétence, niveau — et il prépare une fiche récapitulative avant de lancer la génération complète.

Pas besoin de remplir un formulaire : parlez à l'IA comme à un collègue.

3.1 — Démarrer une conversation

1

Cliquez sur "💬 Assistant IA" dans la sidebar

Ou cliquez sur l'une des deux cartes de mode (💼 Formation Pro / 🎓 Cours Académique) sur l'écran d'accueil.

2

Décrivez votre module

Tapez votre demande dans le champ en bas du chat et appuyez sur Entrée. Plus vous êtes précis, meilleur sera le résultat.

3

Validez la fiche de synthèse

L'IA vous présente un récapitulatif (titre, domaine, public, durée, niveau). Cliquez sur ⚡ Générer ce module pour lancer la génération complète.

3.2 — Exemples de commandes efficaces

🏭 Formation Professionnelle — exemples

  • "Module sur la maintenance préventive d'une pompe hydraulique, niveau intermédiaire, 3h"
  • "Crée un cours sur le câblage d'armoire industrielle pour des apprentis électriciens débutants"
  • "Formation au diagnostic de panne sur automate Siemens S7, techniciens confirmés"
  • "Module soudure TIG sur acier inoxydable, formation 2 jours, niveau débutant"

🎓 Cours Académique — exemples

  • "Cours sur la transformée de Laplace pour des étudiants de BUT2 en automatique"
  • "Module sur les machines asynchrones triphasées, Licence Pro électrotechnique"
  • "Cours sur les systèmes de régulation PID pour Master Ingénierie M1"
  • "Chapitre résistance des matériaux — flexion simple, Ingénieur 1ère année"
💡 Plus de détails = meilleur résultat Mentionnez le domaine exact, le niveau du public, la durée souhaitée, les outils ou normes si pertinent.

3.3 — Insérer des documents sources

Fonctionnalité clé

Glissez-déposez vos propres documents (PDF, Word, TXT) dans le chat. L'IA lit l'intégralité du document — début ET fin — et en extrait les informations les plus importantes pour enrichir le module généré.

Comment insérer un document

  • Cliquez sur l'icône 📎 en bas du chat, ou glissez-déposez le fichier dans la zone de chat
  • Un toast "📄 Lecture complète de fichier.pdf…" confirme que le document est en cours d'analyse
  • Vous pouvez insérer plusieurs documents — ils sont tous pris en compte
  • L'IA extrait les notions clés, données numériques et procédures même si elles sont à la fin du document
💡 Cas d'usage typiques Chargez un cours existant, un manuel technique, une fiche de poste ou un rapport d'audit — l'IA construit le module à partir de votre contenu réel, pas d'un contenu générique.

3.4 — Comprendre la génération en direct

L'écran de génération

Une fois lancée, la génération affiche un écran dédié avec :

  • Une barre de progression qui avance au fil des étapes
  • Des étapes numérotées (plan → sections → cas terrain → quiz → mémo) avec statut en temps réel
  • Une liste live des sections rédigées : chaque titre apparaît au fur et à mesure, avec un ✓ vert

La génération parallèle rédige toutes les sections en même temps — beaucoup plus rapide qu'une rédaction séquentielle.

⚠️ Ne fermez pas l'onglet pendant la génération Si vous fermez ou rechargez la page avant la fin, la génération est perdue. Attendez que le module s'ouvre automatiquement.

Section 4

Explorer un module généré

Tout ce que contient un module et comment l'utiliser efficacement

Structure d'un module

Une fois généré, le module s'ouvre dans le visualiseur. En haut, des boutons d'action sont disponibles, suivis d'un bandeau coloré (adapté à votre domaine) avec le titre, le domaine et les métadonnées.

Les contenus sont organisés en cartes empilées : objectifs, sections de cours, cas terrain, exercices, quiz, et les nouvelles cartes (plan de révision, vidéos YouTube).

← Bibliothèque 🃏 Flashcards 🏅 Attestation 🖼️ Images 📋 Dupliquer 📄 Exporter PDF

4.1 — Les sections de cours

Contenu d'une section

Chaque section est un accordéon cliquable (cliquez sur l'en-tête coloré pour l'ouvrir). À l'intérieur :

  • Le contenu principal — cours rédigé avec étapes progressives
  • Les points de vigilance (Pro) — risques et seuils critiques
  • Le réflexe pro — le savoir implicite de l'expert
  • Les définitions (Acad) — glossaire intégré dans la section
  • Les exemples (Acad) — applications concrètes de la théorie
  • Un schéma IA — diagramme de flux généré à la demande
  • Une image illustrative — photo ajoutée via le bouton "🖼️ Images"

Barre de progression de lecture

En haut de la carte "Sections", une barre verte indique combien de sections vous avez lues. Cliquez sur la pastille colorée à gauche de chaque titre de section pour la marquer comme lue — elle passe en vert.

Prendre des notes sur une section

Dans chaque section ouverte, un bouton + Note ouvre un champ texte personnel. Vos notes sont sauvegardées avec le module et affichées à chaque réouverture, sur fond jaune pour les repérer facilement.

4.2 — Exercices et mises en situation

💼 Formation Pro

  • Mises en situation terrain progressives (débutant → expert) avec contexte, consigne, indices et correction
  • Cas terrain avec entreprise fictive, données chiffrées, problème et contraintes réelles
  • Check-list Avant / Pendant / Après l'intervention
  • Mémo terrain avec règles fondamentales et règle d'or

🎓 Cours Académique

  • Exercices TD/TP à 3 niveaux (débutant, intermédiaire, avancé) avec énoncé et corrigé complet
  • Cas industriel avec données numériques réalistes
  • Fiche de révision : notions, formules, méthode, pièges classiques
  • Formules clés formatées en bloc monospace

4.3 — Le quiz d'évaluation

Accéder au quiz

Faites défiler jusqu'à la carte bleu "❓ Quiz de compréhension". Le quiz contient entre 5 et 20 questions QCM (configurable dans les Paramètres). Les questions mélangent 4 types : connaissance factuelle, compréhension du principe, situationnel et diagnostic.

1

Sélectionnez une réponse par question

Cliquez sur la ligne de la réponse. Elle se colore en doré (Pro) ou violet (Académique).

2

Cliquez sur "✓ Soumettre l'évaluation"

L'anneau de score s'anime, affichant votre pourcentage. Bonnes réponses en vert, erreurs en rouge avec explication.

3

Consultez les boutons d'action

Trois options après résultat : 🔄 Recommencer 🎯 Revoir mes erreurs 📚 Remédiation IA

85%
✅ Module validé — excellente maîtrise !

17 / 20 bonnes réponses — Minimum requis : 70%

Score sauvegardé automatiquement dans la bibliothèque.

Nouveau

🎯 Revoir mes erreurs — Après un quiz raté, ce bouton lance une session ciblée sur les seules questions que vous avez manquées. Chaque correction donne un feedback avec l'explication de l'erreur. Si vous corrigez tout, une animation de célébration se déclenche.

🎉 Score ≥ 80% — Confettis ! Si vous obtenez 80% ou plus, l'application déclenche une animation de célébration. Votre score est enregistré automatiquement sur la carte du module dans la bibliothèque.

4.4 — 🆕 Micro-quiz par section

Nouveau

Chaque section de cours possède désormais un bouton 🧪 Tester dans son contenu étendu. Il affiche une question du QCM du module directement dans la section, avec feedback immédiat.

Comment utiliser le micro-quiz

1

Ouvrez une section de cours

Cliquez sur l'en-tête coloré d'une section pour l'ouvrir et lire son contenu.

2

Cliquez sur "🧪 Tester" en bas de la section

Ce bouton apparaît à côté de "+ Note" et "🔄 Régénérer", dans la barre d'actions de la section ouverte.

3

Répondez à la question

Une question QCM liée à la section s'affiche sur fond jaune. Cliquez sur votre réponse — la bonne réponse s'affiche en vert, les mauvaises en rouge, et l'explication apparaît automatiquement.

💡 Pourquoi c'est important Des études en sciences cognitives montrent que tester sa compréhension pendant la lecture (et pas seulement après) augmente la mémorisation de 40%. C'est le principe du test effect ou "retrieval practice".

3 jours 7 jours 14 jours 30 jours

Cliquez sur une durée — le plan se génère instantanément, sans IA, directement depuis le contenu du module.

4.6 — 🆕 Images et vidéos YouTube

🖼️ Images automatiques

Le bouton 🖼️ Illustrer en haut du module ajoute une image générée par IA à chaque section, adaptée au contenu.

  • Aucune clé API requise — 100% gratuit et illimité
  • Images générées par Pollinations AI (modèle Flux), contextualisées par mots-clés
  • Chaque section reçoit une image unique et reproductible (graine fixe)
  • Bouton 🔄 Réillustrer pour régénérer toutes les images
  • Bouton "🗑️ Retirer image" pour supprimer une image individuelle

📺 Vidéos YouTube

La carte "📺 Ressources vidéo" affiche 5 liens de recherche YouTube générés automatiquement à partir du contenu du module.

  • Recherche globale sur le titre du module
  • Recherche par domaine/secteur
  • Une recherche par section (les 3 premières)
  • Cliquez pour ouvrir YouTube dans un nouvel onglet

Vous pouvez désactiver cette carte dans Paramètres → Sections affichées → 📺 Vidéos YouTube.

4.8 — Flashcards et mémorisation

L'interface Flashcards

Le bouton 🃏 Flashcards en haut du module ouvre une session de révision par cartes retournables :

  • Face recto — le terme technique (fond sombre)
  • Face verso — la définition complète (fond blanc)
  • Cliquez sur la carte pour la retourner (animation 3D)
  • Naviguez avec les boutons ← → ou les touches clavier
  • Le compteur indique votre position (ex : 4 / 12)
💡 Idéal pour la révision la veille d'un examen Parcourez les flashcards sans regarder les réponses, retournez uniquement celles sur lesquelles vous hésitez. Répétez jusqu'à maîtriser le deck complet.

4.9 — Attestation et export PDF

📄 Exporter votre module en PDF

Le bouton 📄 Exporter PDF génère une version imprimable complète du module (sections, étapes, quiz avec corrigés, formules). La boîte d'impression s'ouvre automatiquement — choisissez "Enregistrer en PDF".

🏅 Attestation (Formation Pro uniquement)

Le bouton 🏅 Attestation génère un certificat avec le nom de la plateforme, le titre du module, la date et le score. Configurez votre nom et celui du formateur dans ⚙️ Paramètres → Identité.

Pour aller plus loin, cliquez sur les liens YouTube générés par le module pour trouver des ressources complémentaires adaptées.

9

Section 7

FAQ — Questions fréquentes

Les réponses aux questions les plus courantes

La génération est bloquée / ne démarre pas

Cause la plus fréquente : clé API absente ou non reconnue. Vérifiez que votre clé est bien saisie et que le badge ✨ Gemini apparaît sous le champ. Si le champ est vide ou que la clé n'est pas reconnue, aucune génération n'est possible.

Autres causes :

  • Quota gratuit atteint (variable selon Google) → attendez 1 minute
  • Connexion internet instable → vérifiez votre réseau
  • Le modèle sélectionné est temporairement indisponible → réessayez, l'application bascule automatiquement sur une autre variante

Mes modules ont disparu

Les modules sont dans le localStorage de votre navigateur. Ils disparaissent si vous videz le cache, changez de navigateur, ou ouvrez en navigation privée.

Bonne pratique : exportez régulièrement. ⬆️ Exporter crée un fichier .json ré-importable à tout moment.

Le bouton "🖼️ Illustrer" ne fonctionne pas

Les images sont générées par Pollinations AI (aucune clé requise). Si elles ne s'affichent pas, vérifiez votre connexion internet. En cas d'erreur de chargement, une image de secours SVG s'affiche automatiquement. Utilisez le bouton 🔄 Réillustrer pour forcer une nouvelle tentative sur toutes les sections.

Les vidéos YouTube ne correspondent pas bien au module

Les liens YouTube sont des recherches automatiques basées sur le titre et les sections — ils ouvrent des résultats de recherche, pas des vidéos sélectionnées manuellement. Si les résultats ne sont pas pertinents, affinez la recherche directement dans YouTube en ajoutant des mots-clés spécifiques à votre domaine.

Je vois le plan de révision mais pas la carte vidéos

Allez dans ⚙️ Paramètres → Sections affichées et vérifiez que "📺 Vidéos YouTube" est activé. Vous pouvez activer/désactiver chaque section indépendamment depuis cet écran.

Le micro-quiz affiche toujours la même question

Le micro-quiz choisit une question de façon cyclique en fonction du numéro de la section. Si votre module a peu de questions QCM, certaines sections peuvent afficher la même question. Utilisez 🔄 Nouveau quiz pour régénérer un quiz plus varié.

Le quiz ne correspond pas bien au cours

Utilisez le bouton 🔄 Nouveau quiz dans la carte Quiz pour en régénérer un nouveau à partir du même contenu. Chaque génération produit des questions différentes.

Le cas terrain / industriel est vide

Si la génération initiale n'a pas produit de cas, un bouton 🔄 Générer le cas apparaît dans la section correspondante. Cliquez dessus pour le générer à la demande — cela ne régénère que cette partie du module.

Combien de modules puis-je créer ?

Il n'y a pas de limite dans Green Lab Studio. La seule contrainte est le quota gratuit de Gemini (Google), variable selon le modèle et qui se réinitialise régulièrement.

En pratique, vous pouvez générer plusieurs modules par heure sans frais.

Le contenu généré n'est pas assez spécialisé

Soyez plus précis dans votre description :

  • ❌ "maintenance" → ✅ "maintenance préventive de compresseur à vis en industrie alimentaire"
  • ❌ "automatisme" → ✅ "programmation d'un automate Siemens S7-1500 en Ladder"

Vous pouvez aussi insérer un document source (cours existant, manuel technique) pour ancrer la génération dans votre contenu réel.
